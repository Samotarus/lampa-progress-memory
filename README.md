# Lampa Progress Memory 1.1.0

Автономный плагин Lampa, сохраняющий прогресс просмотра по TMDB ID и (для сериалов) сезону/серии. История не зависит от magnet-ссылки, torrent hash, качества или имени файла.

## Установка

1. Соберите проект командой `npm run build` или используйте готовый `dist/progress.js`.
2. Разместите `dist/progress.js` на HTTPS-хостинге (например, GitHub Pages).
3. В Lampa откройте **Настройки → Расширения → Добавить плагин** и вставьте URL файла `progress.js`.

Плагин не требует Node.js на приставке. При отсутствии API Lampa он безопасно загружается, но соответствующая интеграция будет недоступна.

## Возможности

- ключи `movie:{tmdb_id}` и `tv:{tmdb_id}:s{season}:e{episode}`;
- сохранение позиции через интервалы, паузу, остановку и завершение;
- порог завершения 90% (настраивается 75–99%);
- защита от одиночной перемотки в конец через накопленное непрерывное время;
- восстановление после перезапуска через `Lampa.Storage`/`localStorage`;
- экспорт/импорт JSON через `LampaProgressMemory.export()` и `.import()`;
- ручные действия `LampaProgressMemory.mark(meta, true|false)` и `.remove(meta)`;
- ручная установка процента через `LampaProgressMemory.setProgress(meta, percent, duration)`;
- обработчики встроенного плеера и best-effort событий Vimu/Lampa Listener;
- повторная инициализация не создаёт второй набор обработчиков.
- постоянный блок в полноэкранной карточке `.full-start-new` и на карточках каталога `.card__view`;
- сводка сериала по всем сохранённым эпизодам и экран диагностики в настройках.

Диагностика открывается в **Настройки → Progress Memory → Открыть диагностику**. Она показывает доступность `Lampa.Storage`, `Lampa.Player.listener`, `Lampa.PlayerVideo.listener`, последний распознанный ID/эпизод, таймкод, число записей и последнюю ошибку.

## Ограничения

Адаптер сверён с актуальной документацией `yumata/lampa-source`: `Lampa.Player.listener` (`start`, `ready`, `destroy`, `close`, `external`) и пересоздаваемый `Lampa.PlayerVideo.listener` (`timeupdate` с `{current,duration}`, `pause`, `ended`). Он подписывается на `PlayerVideo` только после `Player:start` и удаляет слушатели при `destroy`. События TorrServer дают карточку в `Player:start`; torrent hash используется только как признак источника и не входит в ключ истории.

Точные имена событий и формат результата Vimu зависят от версии Lampa и конкретного внешнего плеера. Для Vimu позиция сохраняется только если Lampa вернула её через подтверждённый callback/событие; вымышленное значение не записывается.
