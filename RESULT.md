# Результат Lampa Progress Memory

## Реализовано

- `dist/progress.js` и корневой `progress.js` — единый автономный JavaScript-файл для загрузки в Lampa; второй файл позволяет GitHub Pages отдавать URL `/progress.js`.
- Идентификация фильмов и сериалов по TMDB ID; эпизодный ключ включает сезон и серию.
- История не использует torrent hash, magnet URI или имя раздачи как идентификатор.
- Устойчивое хранилище с версией схемы, очисткой повреждённых записей, защитой от отката позиции, экспортом и импортом JSON.
- Сохранение прогресса встроенного плеера по таймеру, при паузе/остановке/завершении.
- Порог завершения по умолчанию 90%, настраиваемый в диапазоне 75–99%.
- Защита от случайной перемотки: крупный скачок позиции не считается накопленным просмотром.
- Восстановление после перезапуска и раздельные записи при переключении сезонов/серий или раздач.
- Безопасная инициализация при отсутствии `Lampa.Storage`, `Lampa.SettingsApi`, `Lampa.Player` или `Lampa.Listener`.
- Best-effort интеграция карточки и событий Lampa/Vimu, ручные API отметки и удаления.

## Проверки

`npm test` проходит 6 автоматических тестов: идентификация, независимость от раздачи, сохранение/восстановление, защита от перемотки, порог, переключение эпизодов и экспорт/импорт. `node --check dist/progress.js` проходит.

Тесты используют mock-хранилище и mock-события Node.js. Совместимость с конкретной версией Lampa, TorrServer и Vimu этими тестами не подтверждается.

## Ограничения и проверка на приставке

Формат событий Vimu различается между сборками. Плагин не подставляет позицию, если Lampa её не возвращает; в таком случае доступна ручная отметка через API карточки. На реальной приставке нужно проверить запуск встроенного плеера, возврат из Vimu и отображение сводки в карточке.

## Установка

Репозиторий опубликован: https://github.com/Samotarus/lampa-progress-memory

После включения GitHub Pages из ветки `main` (корень `/`) файл будет доступен по адресу `https://samotarus.github.io/lampa-progress-memory/progress.js`. Добавьте этот URL в Lampa через **Настройки → Расширения → Добавить плагин**. До включения Pages используйте raw URL: `https://raw.githubusercontent.com/Samotarus/lampa-progress-memory/main/progress.js`.
