# Результат Lampa Progress Memory 1.1.0

## Реализовано

- `dist/progress.js` и корневой `progress.js` — единый автономный JavaScript-файл для загрузки в Lampa; второй файл позволяет GitHub Pages отдавать URL `/progress.js`.
- Идентификация фильмов и сериалов по TMDB ID; эпизодный ключ включает сезон и серию.
- История не использует torrent hash, magnet URI или имя раздачи как идентификатор.
- Устойчивое хранилище с версией схемы, очисткой повреждённых записей, защитой от отката позиции, экспортом и импортом JSON.
- Сохранение прогресса встроенного плеера по таймеру, при паузе/остановке/завершении.
- Порог завершения по умолчанию 90%, настраиваемый в диапазоне 75–99%.
- Защита от случайной перемотки: крупный скачок позиции не считается накопленным просмотром.
- Восстановление после перезапуска и раздельные записи при переключении сезонов/серий или раздач.
- Безопасная инициализация при отсутствии `Lampa.Storage`, `Lampa.SettingsApi`, `Lampa.Player` или `Lampa.Listener`.
- Best-effort интеграция карточки и событий Lampa/Vimu, ручные API отметки и удаления.
- Реальная интеграция с документированными `Lampa.Player.listener` и `Lampa.PlayerVideo.listener` (`current`/`duration`), включая очистку пересоздаваемых слушателей.
- Постоянный блок в `.full-start-new` и `.card__view`, сводка сериала по всем эпизодам, следующая серия и сообщение при пустой истории.
- Диагностический экран из настроек с состоянием API, последним контекстом и ошибкой.

## Проверки

`npm test` проходит 13 автоматических тестов: идентификация, независимость от раздачи, сохранение/восстановление, защита от перемотки, порог, переключение эпизодов, экспорт/импорт, документированные события плеера, агрегация сериала, пустая история и идемпотентность адаптера. `node --check dist/progress.js` проходит.

Тесты используют mock-хранилище и mock-события Node.js. Совместимость с конкретной версией Lampa, TorrServer и Vimu этими тестами не подтверждается.

## Ограничения и проверка на приставке

Формат событий Vimu различается между сборками и не подтверждён исходниками Lampa как универсальный callback. Плагин не подставляет позицию, если Lampa её не возвращает; в таком случае доступна ручная отметка или `setProgress`. Автотесты используют mock-шины и не подтверждают Vimu. На реальной приставке нужно проверить запуск TorrServer, сохранение после паузы/закрытия, возврат из Vimu и отображение сводки в карточке.

## Установка

Репозиторий опубликован: https://github.com/Samotarus/lampa-progress-memory

GitHub Pages включён из ветки `main` (корень `/`) и проверен: `https://samotarus.github.io/lampa-progress-memory/progress.js` отдаёт версию 1.1.0. Добавьте этот URL в Lampa через **Настройки → Расширения → Добавить плагин**. Raw URL также доступен: `https://raw.githubusercontent.com/Samotarus/lampa-progress-memory/main/progress.js`.
